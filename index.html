Six areas, one pass

Measured, not guessed — and a check that cannot run is reported as skipped with the reason, never silently passed.

security · 34% weight

Hardening, end to end

  • TLS version + expiry
  • HSTS and redirect chain
  • CSP quality, not just presence
  • clickjacking · cookies · mixed content
  • server version disclosure
accessibility

axe-core in a real browser

  • WCAG 2.1 A/AA + best practice
  • contrast, labels, landmarks, headings
  • lang, viewport, image alt
  • exact CSS selector per failure
performance

Core Web Vitals

  • FCP · LCP · CLS · DOM size
  • transfer weight + request count
  • heaviest resources listed
  • cold vs warm load compared
seo

Discoverability

  • title + description length
  • canonical · Open Graph · JSON-LD
  • robots.txt · sitemap.xml
  • sampled broken internal links
code

Repo hygiene

  • dependency CVEs (npm / pip)
  • lockfile, test/lint/typecheck scripts
  • .gitignore coverage for secrets
  • runtime console errors
privacy

Third parties & surface

  • CORS wildcard vs credentials
  • COOP / CORP
  • tracker hosts detected by name

Install

No pip install, no npm install — the browser driver and axe-core are vendored. Needs python3 3.9+, node and a local Chrome or Chromium.

One line

Clones the skill, links the CLI, wires every agent it finds.

curl -sL https://audit.jrispace.com/install.sh | bash

Audit a live site

Headers, CSP, axe, vitals, SEO and links in one pass.

audit https://your-site.com

Audit a codebase

Static gate, dependency CVEs, repo hygiene.

audit ~/Projects/your-app --deep

Gate your CI

Exit code 3 when the grade falls below C.

audit "$URL" --no-browser --json

Works as an agent skill

The repo is a standard Agent Skill — SKILL.md plus scripts. Symlink it once and any coding agent can audit before it claims the work is finished.

Claude Code

Skills directory, auto-discovered.

ln -s "$PWD" ~/.claude/skills/webapp-audit

Hermes Agent

Loaded on demand from the skill index.

ln -s "$PWD" ~/.hermes/skills/quality/webapp-audit

Codex CLI

Adds an /audit prompt.

cp prompts/audit.md ~/.codex/prompts/

Cursor

Adds a rule that fires on “audit”.

cp rules/audit.mdc ~/.cursor/rules/

Then ask normally — “audit my site”, “is this production-ready?” — and the agent runs the tool, reads the report and gives you the grade table with the blocking findings.
